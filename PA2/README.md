# RELAY RUN — PA2 Portfolio Edition

원본 PA2의 장애물 회피 게임을 3구역 타임어택 코스로 확장한 Unity 프로젝트입니다.
Unity **2022.3.29f1**, Built-in Render Pipeline, 키보드 조작 기준입니다.
저장소에는 Unity 프로젝트 소스만 포함하며 배포용 실행 파일은 포함하지 않습니다.

## 실행

1. Unity Hub에서 이 `PA2` 폴더를 프로젝트로 추가합니다.
2. `Assets/Portfolio/Scenes/RelayRun.unity`를 엽니다.
3. Play를 누르고 `ENTER THE COURSE` 또는 Enter로 시작합니다.

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 이동 |
| Space + 이동 방향 | 대시, 대시 중 장애물 피해 회피 |
| Esc | 일시정지 / 재개 |
| M | 효과음 켜기 / 끄기 |
| Enter | 시작 / 결과 화면에서 재시도 |

## 플레이 규칙

150초 안에 릴레이 3개를 순서대로 활성화하고 마지막 게이트를 통과합니다.
체력은 100, 장애물 피격은 20이며 피격 후 1.2초 보호 시간이 있습니다.
대시 쿨다운은 1.1초입니다. 청록색 구체는 체력을 20 회복하고, 릴레이는
체력을 10 회복하며 체크포인트를 저장합니다. 낙하하면 체크포인트로 복귀합니다.

- 01 CROSS TRAFFIC: 좌우로 이동하는 장애물의 간격을 읽는 구역.
- 02 ANGULAR MOMENTUM: 회전 막대의 궤적을 피하는 구역.
- 03 PULSE ARRAY: 주황 경고 타일을 보고 올라오는 기둥을 통과하는 구역.

완주 시간과 피격 횟수로 등급을 매깁니다. S는 무피격·65초 미만,
A는 2회 이하 피격·95초 미만, B는 5회 이하 피격, 그 외 C입니다.
개인 최고 완주 시간과 음소거 설정은 로컬 PlayerPrefs에 저장됩니다.

## 코드 구조

| 파일 | 책임 |
|---|---|
| `RunSession` | 세션 상태, 시간, 체력, 체크포인트, 기록 |
| `Runner` | CharacterController 이동, 대시, 애니메이션 |
| `CourseHazard` | 이동·회전·펄스 패턴과 피해 |
| `CoursePickup` | 릴레이, 회복, 출구 트리거 |
| `RunCamera` | 추적 카메라, 피격 흔들림 |
| `RunHUD` | 반응형 Canvas HUD와 메뉴 / 결과 화면 |
| `PortfolioBuilder` | Unity Editor API를 통한 씬·머티리얼 생성 |
| `CourseTests` | 실제 씬을 사용하는 Play Mode 통합 테스트 |

`PA2 > Build Portfolio Scene` 메뉴는 씬을 재생성합니다. **수동으로 씬을 편집했다면
먼저 복사본을 저장하세요.** 재생성하면 해당 개선 씬이 생성 코드 기준으로 교체됩니다.
실행 파일 빌드 메뉴는 추가하지 않았습니다.

## 원본과 기여 구분

원본 `Assets/Scenes`의 start, main, Over, Clear 씬과 기존 스크립트를 보존했습니다.
기존 씬을 실행하려면 원하는 원본 씬을 직접 여세요. 원본의 씬 간 전환까지
테스트하려면 Build Settings에서 원본 4개 씬도 활성화해야 합니다.
새 기능은 `Assets/Portfolio`에 분리했습니다.

캐릭터 모델·애니메이션은 제공된 **Goldmetal Studio의 `QuarterView 3D Action BE5`**
에셋을 재사용했습니다. 원본 ReadMe의 출처 표기 조건에 따라 이 크레딧을 유지하세요.
새 코스 형상·머티리얼·UI·짧은 합성 효과음은 프로젝트 안에서 생성됩니다.
외부 모델이나 Meshy 생성 모델은 현재 사용하지 않았습니다.

## 검증

Window > General > Test Runner에서 PlayMode의 `CourseTests`를 실행할 수 있습니다.
이동·대시·보호 시간·일시정지, 실제 릴레이/회복 트리거, 체크포인트 복귀,
출구 잠금·클리어, 체력 소진·재시도 초기화를 검증합니다.
테스트는 최고 기록을 갱신하지 않습니다.

## 포트폴리오 소개 예시

> PA2 장애물 회피 프로토타입을 3구역 타임어택 게임 Relay Run으로 확장했습니다.
> 이동·회전·시간차 기둥 패턴을 구성하고, 대시 회피와 피격 보호 시간으로 조작에
> 대응할 수 있는 규칙을 만들었습니다. 체크포인트·체력 회복·순차 릴레이 목표,
> 메뉴·HUD·결과 화면·로컬 최고 기록을 연결했습니다. Play Mode 통합 테스트로
> 이동과 트리거, 세션 전환을 검증하도록 구성했습니다.

권장 시연 순서는 시작 화면 → 대시 회피 → 릴레이 활성화 → 회복 → 펄스 구역 → 결과 화면입니다.
